## Goal

在 M0–M4 完整 S3 + IAM/策略 + 高级特性后端之上，构建 **MinIO Console 式的 LiveView 管理控制台**，跑在既有 `MaxioWeb.Endpoint`（:4000，物理隔离于 S3 Endpoint :9900/:9000）。Console 直接调用 maxio context 做可视化管理：

1. **CONSOLE AUTH + SHELL（M5-1/M5-2）**：会话登录（access_key + secret_key 经 `CredentialStore.get_secret/1` 常数时间比对）+ `on_mount` 鉴权钩子 + `live_session` 双块（public/protected）+ 登出 + **侧边栏导航 app shell**（Dashboard / Buckets / Access Keys / Settings）+ `window.__maxio` 调试钩子。
2. **DASHBOARD（M5-3）**：桶数 / 对象数（当前版本）/ 总用量 / per-bucket 大小 / access key 数 / 进行中 multipart —— 廉价 SQL 聚合（直接 `Repo.aggregate` + context）。
3. **BUCKETS 列表 + CREATE/DELETE（M5-4）**：streams 列表；创建表单（`Buckets.create/3` 名校验）；删除（`Buckets.delete/1` 非空守卫 → flash）；region/创建时间列。
4. **OBJECT BROWSER（M5-5）**：per-bucket 对象列表 + prefix/folder 面包屑导航（`list_objects_v2/2` delimiter）；**上传**（`allow_upload` 流式喂 `Storage.put` + `Objects.put_version_with_id`，版本化感知）；**下载**（plain controller `send_chunked` 流式）；新建文件夹（零字节 `prefix/` 对象）；删除（`insert_delete_marker`/`delete_metadata`）。
5. **OBJECT DETAIL（M5-6）**：对象详情（size/etag/last-modified/content-type/version_id）+ **tags 编辑**（`get_tags`/`put_tags` + `Tags.validate`）+ **版本列表**（`list_object_versions/2`，含 delete marker，per-version 下载/删除）。
6. **BUCKET CONFIG 编辑（M5-7）**：versioning toggle（`put_versioning/3`）+ bucket policy JSON 编辑器（`Policy.Store` + `Statement.parse_policy` 校验）+ canned ACL（`put_acl/2`）+ bucket tags（`get_tags`/`put_tags`）+ CORS（`BucketConfigs` :cors + `Cors`）+ lifecycle（`BucketConfigs` :lifecycle，明确标注「后台执行 defer」）+ 默认加密 SSE-S3 toggle（`BucketConfigs` :encryption，KMS 灰显）。
7. **ACCESS KEYS（M5-8）**：列表/创建（创建后只显示一次 secret）/删除（`Maxio.IAM`，root 保护 `:cannot_delete_last_root`）。
8. **POLISH + e2e 矩阵 + 文档（M5-9）**：world-class Tailwind UI 收尾、跨页 LiveViewTest 矩阵、STATUS 更新、README Console 章节（含 defer 清单）。

**显式不做（defer，到达即文档化，绝不静默放行/假装实现）**：
- **Identity → Users / Groups / IAM identity policies / STS / IdP**：maxio 无独立 user/group 实体（M3 defer，`principal_policies/1` 恒 `[]`）。Console 用 **access key** 作 identity primitive；Users/Groups 在侧边栏**不出现**（不画灰条目假装有），README 文档化。
- **Bucket → Quota / Events-Notifications / Replication / Object-Lock-Retention-Legal-Hold**：后端未实现。Settings 页不画这些 tab。
- **Object → Legal hold / Retention**：后端未实现，对象详情不展示。
- **Object Preview（内联预览）**：MVP 不做（仅下载）。SSE 对象 GET 全缓冲 + Range 降级（M4 defer），故大加密对象预览风险——直接 defer 预览。
- **Share / 预签名 URL（M5-4 可选）**：可用 `Maxio.Auth.SigV4.Signer` 生成指向 S3 Endpoint 的预签名 GET（唯一引用 S3 HTTP 之处）。**MVP 标为可选**，若时间不足则 defer 并文档化（不画死按钮）。
- **Monitoring → Logs/Trace/Audit 流 / Drives/Heal / 流量·API速率·延迟 时序图**：需 Prometheus/纠删码（M6）。Dashboard 只做廉价计数，不画时序图。
- **Configuration/Settings 运行时编辑 / Tiers / Site Replication / Batch Jobs / License**：后端无运行时配置存储；不做。
- **Multipart 大文件上传（Console 侧）**：MVP 走单 PUT 路径（`max_file_size` 上限 5 GiB，服务端临时文件中转）；接 `Maxio.Multipart` 的逐 part 上传标 `VERIFY-AT-IMPL: console multipart`，文档化为后续优化。

## 全局命名契约（M5 新增，一次定义全程复用；M0–M4 既有契约见对应计划）

**沿用既有 context 签名（已核验，逐字一致，executor 复用时照抄）**：
- `Maxio.Buckets.list/0 :: [%Bucket{}]`（按 name 升序，字段 `name/region/owner/acl_canned/versioning/mfa_delete/tags/inserted_at/updated_at`）。
- `Maxio.Buckets.create(name, owner, opts \\ []) :: {:ok, %Bucket{}} | {:error, :invalid_bucket_name | :already_owned | Ecto.Changeset.t()}`（opts: `:region`、`:acl_canned`）。
- `Maxio.Buckets.lookup(name) :: {:ok, %Bucket{}} | {:error, :not_found}`。
- `Maxio.Buckets.delete(name) :: :ok | {:error, :not_found | :not_empty}`。
- `Maxio.Buckets.validate_name(name) :: :ok | {:error, :invalid_bucket_name}`。
- `Maxio.Buckets.put_versioning(name, status, mfa) :: :ok | {:error, :not_found}`（status ∈ `"Enabled"|"Suspended"|nil`）。
- `Maxio.Buckets.put_acl(name, canned) :: :ok | {:error, :not_found}`。
- `Maxio.Buckets.get_tags(name) :: {:ok, [{k,v}]} | {:error, :not_found}`；`Maxio.Buckets.put_tags(name, [{k,v}]) :: :ok | {:error, :not_found}`。
- `Maxio.Objects.list_objects_v2(bucket, opts_map) :: %{objects: [%Object{}], common_prefixes: [String], is_truncated: bool, next_continuation_token: String|nil, key_count: int}`（opts: `:prefix/:delimiter/:max_keys/:continuation_token/:start_after`）。
- `Maxio.Objects.list_object_versions(bucket, opts_map) :: %{versions: [%Object{}], common_prefixes, is_truncated, next_key_marker, next_version_id_marker}`（`%Object{}` 含 `is_delete_marker/version_id/is_latest`）。
- `Maxio.Objects.get_metadata(bucket, key) :: {:ok, %Object{}} | {:error, :not_found}`（返回 is_latest 行，可能是 delete marker）。
- `Maxio.Objects.get_version(bucket, key, version_id) :: {:ok, %Object{}} | {:error, :not_found}`。
- `Maxio.Objects.put_version_with_id(bucket, key, version_id, attrs) :: {:ok, %Object{}} | {:error, :no_such_bucket | Ecto.Changeset.t()}`（attrs 至少 `:size/:etag`，可含 `:content_type/:metadata/:storage_class/:acl_canned/:tags/:sse_algorithm/:sse_envelope`）。
- `Maxio.Objects.insert_delete_marker(bucket, key, versioning) :: {:ok, %{version_id}} | {:error, :no_such_bucket}`。
- `Maxio.Objects.delete_metadata(bucket, key) :: :ok`（幂等，删所有版本行）。
- `Maxio.Objects.delete_version(bucket, key, version_id) :: {:ok, %{was_delete_marker: bool}} | {:error, :not_found}`。
- `Maxio.Objects.get_tags(bucket, key, vid \\ nil) :: {:ok, [{k,v}]} | {:error, :not_found}`；`Maxio.Objects.put_tags(bucket, key, [{k,v}], vid \\ nil) :: :ok | {:error, :not_found}`。
- `Maxio.Storage.put(bucket, key, version_id \\ "null", chunks, opts \\ []) :: {:ok, %{size, etag, sha256}} | {:error, term}`（chunks 为 Enumerable，`File.stream!` 直通不缓冲）。
- `Maxio.Storage.get(bucket, key, version_id \\ "null", range \\ nil) :: {:ok, Enumerable.t()} | {:error, term}`。
- `Maxio.Storage.delete(bucket, key, version_id \\ "null") :: :ok | {:error, term}`。
- `Maxio.IAM.list_access_keys/0 :: [%{access_key_id, principal_arn, type, status}]`（不回 secret）。
- `Maxio.IAM.create_access_key(opts \\ []) :: {:ok, %{access_key_id, secret_key, principal_arn, type}} | {:error, Ecto.Changeset.t()}`。
- `Maxio.IAM.delete_access_key(ak) :: :ok | {:error, :cannot_delete_last_root}`。
- `Maxio.Policy.Store.get_bucket_policy(bucket) :: {:ok, json_binary} | :none`；`put_bucket_policy(bucket, json) :: :ok | {:error, term}`；`delete_bucket_policy(bucket) :: :ok`。
- `Maxio.Policy.Statement.parse_policy(json) :: {:ok, [%Statement{}]} | {:error, :malformed}`（用于 Console 侧 JSON 校验）。
- `Maxio.BucketConfigs.get(bucket, kind) :: {:ok, list()|map()} | :none`（kind ∈ `:cors|:lifecycle|:encryption`）；`put(bucket, kind, value) :: :ok | {:error, term}`；`delete(bucket, kind) :: :ok`。
- `Maxio.Tags.validate([{k,v}], :object|:bucket) :: :ok | {:error, :invalid_tag}`；`Maxio.Tags.map_to_list/1`；`Maxio.Tags.list_to_map/1`。
- `Maxio.Cors.match_actual/3`、`match_preflight/4`（Console 仅展示/编辑规则 JSON，匹配在 S3 端）。
- `Maxio.Auth.CredentialStore.get_secret(ak) :: {:ok, %{secret_key, principal}} | :error`（principal=`%{type: :root|:iam_user, access_key, arn}`）。

**M5 新增模块与签名（跨单元引用，逐字一致）**：
- `MaxioWeb.ConsoleAuth`（M5-1）：
  - `verify_credentials(ak :: String.t(), sk :: String.t()) :: {:ok, principal :: map()} | :error`
  - `log_in(conn, ak :: String.t()) :: Plug.Conn.t()`
  - `log_out(conn) :: Plug.Conn.t()`

### 步骤 2：`MaxioWeb.ConsoleAuth`（凭据验证 + session 助手）

新建 `lib/maxio_web/console_auth.ex`：

```elixir
defmodule MaxioWeb.ConsoleAuth do
  @moduledoc """
  Console 会话鉴权：复用 S3 数据面同一套 `Maxio.Auth.CredentialStore` 验证
  access_key + secret_key（常数时间比对，绝不静默放行，铁律 3）。
  登录成功只把 access_key 落进签名 session（secret 绝不入 session）；
  LiveView mount 时凭 access_key 重新查 principal。
  """
  alias Maxio.Auth.CredentialStore

  @session_key "console_access_key"

  @doc """
  校验 access_key/secret_key。成功返回 `{:ok, principal}`，失败返回 `:error`。
  常数时间比对避免计时侧信道（铁律 3/5）。
  """
  @spec verify_credentials(String.t(), String.t()) :: {:ok, map()} | :error
  def verify_credentials(access_key, secret_key)
      when is_binary(access_key) and is_binary(secret_key) do
    case CredentialStore.get_secret(access_key) do
      {:ok, %{secret_key: stored, principal: principal}} ->
        if Plug.Crypto.secure_compare(stored, secret_key) do
          {:ok, principal}
        else
          :error
        end

      :error ->
        # 即便 access_key 不存在也做一次假比对，抹平计时差（避免枚举 access_key）。
        _ = Plug.Crypto.secure_compare(secret_key, secret_key)
        :error
    end
  end

  def verify_credentials(_, _), do: :error

  @doc "登录后写 session（只存 access_key，renew 防 session fixation）。在 controller 里用。"
  @spec log_in(Plug.Conn.t(), String.t()) :: Plug.Conn.t()
  def log_in(conn, access_key) do
    conn
    |> Plug.Conn.put_session(@session_key, access_key)
    |> Plug.Conn.configure_session(renew: true)
  end

  @doc "登出：清 session。"
  @spec log_out(Plug.Conn.t()) :: Plug.Conn.t()
  def log_out(conn), do: Plug.Conn.configure_session(conn, drop: true)

  @doc "从 session 的 access_key 还原 principal（LiveView on_mount / plug 用）。无/失效 → nil。"
  @spec fetch_principal(map()) :: map() | nil
  def fetch_principal(%{} = session) do
    case Map.get(session, @session_key) do
      ak when is_binary(ak) ->
        case CredentialStore.get_secret(ak) do
          {:ok, %{principal: principal}} -> principal
          :error -> nil
        end

      _ ->
        nil
    end
  end

  def fetch_principal(_), do: nil

  @doc "session key 名（测试/插件复用）。"
  @spec session_key() :: String.t()
  def session_key, do: @session_key
end
```

### 步骤 3：`MaxioWeb.ConsoleAuth.OnMount`（live_session 钩子）

新建 `lib/maxio_web/console_auth/on_mount.ex`：

```elixir
defmodule MaxioWeb.ConsoleAuth.OnMount do
  @moduledoc """
  `live_session` 的 `on_mount` 钩子：
    * `:require_authenticated` —— 受保护页；无 principal 即 halt 重定向到 /login。
    * `:mount_current_principal` —— 公共页（如 /login）只取 principal，不强制。
  钩子在 dead 与 connected 两次 mount 都跑；重定向必须 halt（否则 LiveView raise）。
  """
  import Phoenix.Component, only: [assign_new: 3]
  import Phoenix.LiveView, only: [redirect: 2]

  alias MaxioWeb.ConsoleAuth

  def on_mount(:require_authenticated, _params, session, socket) do
    socket =
      assign_new(socket, :current_principal, fn ->
        ConsoleAuth.fetch_principal(session)
      end)

    if socket.assigns.current_principal do
      {:cont, socket}
    else
      {:halt, redirect(socket, to: "/login")}
    end
  end

  def on_mount(:mount_current_principal, _params, session, socket) do
    {:cont,
     assign_new(socket, :current_principal, fn -> ConsoleAuth.fetch_principal(session) end)}
  end
end
```

```elixir
defmodule MaxioWeb.SessionController do
  use MaxioWeb, :controller

  alias MaxioWeb.ConsoleAuth

  # GET /login：渲染登录表单（plain HTML，无 LiveView）。
  def new(conn, _params) do
    render(conn, :new, error_message: nil, page_title: "登录 maxio Console", layout: false)
  end

  # POST /login：校验凭据 → 设 session 跳转 /；失败回渲染错误（不泄露是 ak 还是 sk 错，铁律 3）。
  def create(conn, %{"creds" => %{"access_key" => ak, "secret_key" => sk}}) do
    case ConsoleAuth.verify_credentials(ak, sk) do
      {:ok, _principal} ->
        conn
        |> ConsoleAuth.log_in(ak)
        |> put_flash(:info, "登录成功")
        |> redirect(to: ~p"/")

      :error ->
        conn
        |> put_flash(:error, "Access Key 或 Secret Key 无效")
        |> render(:new, error_message: "凭据无效", page_title: "登录 maxio Console", layout: false)
    end
  end

  def create(conn, _params) do
    conn
    |> put_flash(:error, "缺少凭据")
    |> render(:new, error_message: "缺少凭据", page_title: "登录 maxio Console", layout: false)
  end

  # DELETE /logout：清 session 跳回 /login。
  def delete(conn, _params) do
    conn
    |> ConsoleAuth.log_out()
    |> put_flash(:info, "已登出")
    |> redirect(to: ~p"/login")
  end
end
```

## M5-3 · Dashboard（廉价聚合）

```elixir
defmodule Maxio.Console.Stats do
  @moduledoc """
  Console Dashboard 廉价聚合（直接 Repo 聚合，无 Prometheus；时序/流量 defer 见计划）。
  object_count/total_size 只算当前版本（is_latest=true 且非 delete marker），与 ListObjectsV2 口径一致。
  """
  import Ecto.Query
  alias Maxio.Repo
  alias Maxio.Buckets.Bucket
  alias Maxio.Objects.Object
  alias Maxio.Multipart.Upload

  @type t :: %{
          bucket_count: non_neg_integer(),
          object_count: non_neg_integer(),
          total_size: non_neg_integer(),
          access_key_count: non_neg_integer(),
          multipart_count: non_neg_integer(),
          per_bucket: [%{name: String.t(), object_count: non_neg_integer(), size: non_neg_integer()}]
        }

  @doc "汇总 Dashboard 所需全部计数。"
  @spec dashboard() :: t()
  def dashboard do
    current = from o in Object, where: o.is_latest == true and o.is_delete_marker == false

    %{
      bucket_count: Repo.aggregate(Bucket, :count, :id),
      object_count: Repo.aggregate(current, :count, :id),
      total_size: Repo.aggregate(current, :sum, :size) || 0,
      access_key_count: length(Maxio.IAM.list_access_keys()),
      multipart_count: Repo.aggregate(Upload, :count, :id),
      per_bucket: per_bucket()
    }
  end

  defp per_bucket do
    from(o in Object,
      where: o.is_latest == true and o.is_delete_marker == false,
      group_by: o.bucket_name,
      select: %{
        name: o.bucket_name,
        object_count: count(o.id),
        size: coalesce(sum(o.size), 0)
      },
      order_by: [asc: o.bucket_name]
    )
    |> Repo.all()
  end
end
```

```elixir
  alias Maxio.Buckets

  @impl true
  def mount(_params, _session, socket) do

     |> assign(:page_title, "Buckets")
     |> assign(:bucket_count, length(buckets))

  @impl true
  def render(assigns) do
    ~H"""

        Buckets

        class="flex gap-2 items-end mb-6"
      >
        <div class="flex-1 max-w-sm">

        </div>

          <.icon name="hero-plus" class="size-4" /> 创建
        </.button>
      </.form>

      <table class="table table-zebra">
        <thead>
          <tr><th>名称</th><th>区域</th><th>版本化</th><th>创建时间</th><th class="w-0"></th></tr>
        </thead>
        <tbody id="buckets" phx-update="stream">
          <tr class="hidden only:table-row" id="buckets-empty">
            <td colspan="5" class="text-center text-base-content/60">暂无桶，创建一个开始。</td>
          </tr>
          <tr :for={{dom_id, bucket} <- @streams.buckets} id={dom_id}>
            <td>
              <.link navigate={~p"/buckets/#{bucket.name}/browse"} class="link link-primary font-medium">
                {bucket.name}
              </.link>
            </td>
            <td>{bucket.region}</td>
            <td>
              <span class={[
                "badge badge-sm",
                bucket.versioning == "Enabled" && "badge-success",
                bucket.versioning != "Enabled" && "badge-ghost"
              ]}>
                {bucket.versioning}
              </span>
            </td>
            <td class="text-sm text-base-content/70">
              {Calendar.strftime(bucket.inserted_at, "%Y-%m-%d %H:%M")}
            </td>
            <td>
              <div class="flex gap-2 justify-end">
                <.link navigate={~p"/buckets/#{bucket.name}/settings"} class="btn btn-ghost btn-sm">
                  <.icon name="hero-cog-6-tooth" class="size-4" />
                </.link>
                <.button
                  id={"delete-bucket-#{bucket.name}"}
                  phx-click="delete_bucket"
                  phx-value-name={bucket.name}
                  data-confirm={"确定删除桶 #{bucket.name}？（须为空）"}
                >
                  <.icon name="hero-trash" class="size-4" />
                </.button>
              </div>
            </td>
          </tr>
        </tbody>

  @impl true
  def handle_event("create_bucket", %{"bucket" => %{"name" => name}}, socket) do
    owner = socket.assigns.current_principal.arn

    case Buckets.create(name, owner) do
      {:ok, bucket} ->
        {:noreply,
         socket
         |> stream_insert(:buckets, bucket, at: 0)
         |> update(:bucket_count, &(&1 + 1))
         |> put_flash(:info, "已创建桶 #{bucket.name}")
         |> assign(:form, to_form(%{"name" => ""}, as: :bucket))}

      {:error, :invalid_bucket_name} ->
        {:noreply, put_flash(socket, :error, "桶名不符合 S3 命名规则（3-63 位，小写字母/数字/.-，首尾字母数字）")}

      {:error, :already_owned} ->
        {:noreply, put_flash(socket, :error, "桶 #{name} 已存在")}

      {:error, %Ecto.Changeset{} = cs} ->
        {:noreply,
         socket
         |> put_flash(:error, "创建失败")
         |> assign(:form, to_form(cs, as: :bucket))}
    end
  end

  @impl true
  def handle_event("delete_bucket", %{"name" => name}, socket) do
    # stream_delete 需要带真实 id 的 struct——先 lookup 拿 %Bucket{}。
    case Buckets.lookup(name) do
      {:ok, bucket} ->
        case Buckets.delete(name) do
          :ok ->
            {:noreply,
             socket
             |> stream_delete(:buckets, bucket)
             |> update(:bucket_count, &max(&1 - 1, 0))
             |> put_flash(:info, "已删除桶 #{name}")}

          {:error, :not_empty} ->
            {:noreply, put_flash(socket, :error, "桶 #{name} 非空，无法删除")}

          {:error, :not_found} ->
            {:noreply, put_flash(socket, :error, "桶 #{name} 不存在")}
        end

      {:error, :not_found} ->
        {:noreply, put_flash(socket, :error, "桶 #{name} 不存在")}
    end
  end
end
```

```elixir
defmodule MaxioWeb.DownloadController do
  @moduledoc """
  Console 对象下载（plain controller，非 LiveView）。复用 Maxio.S3.Handlers.Object 同构的
  send_chunked + Enum.reduce_while 流式（绝不全缓冲，铁律 4）。
  *key 通配段是路径数组；?versionId= 可指定版本。
  """
  use MaxioWeb, :controller

  alias Maxio.{Objects, Storage}

  def show(conn, %{"bucket" => bucket, "key" => key_segments} = params) do
    key = Enum.join(key_segments, "/")
    version_id = Map.get(params, "versionId")

    fetch =
      if version_id,
        do: Objects.get_version(bucket, key, version_id),
        else: Objects.get_metadata(bucket, key)

    case fetch do
      {:ok, %Objects.Object{is_delete_marker: false} = object} ->
        {:ok, stream} = Storage.get(bucket, key, object.version_id, nil)
        filename = Path.basename(key)

        conn
        |> put_resp_content_type(object.content_type || "application/octet-stream")
        |> put_resp_header("content-disposition", ~s(attachment; filename="#{filename}"))
        |> send_chunked(200)
        |> stream_object(stream)

      _ ->
        conn
        |> put_status(:not_found)
        |> text("Not Found")
    end
  end

  # 逐块 chunk；客户端断开（{:error, :closed}）则优雅 halt。
  defp stream_object(conn, stream) do
    Enum.reduce_while(stream, conn, fn data, acc ->
      case chunk(acc, data) do
        {:ok, acc2} -> {:cont, acc2}
        {:error, :closed} -> {:halt, acc}
      end
    end)
  end
end
```

> `Maxio.Objects.Object` 是 struct 别名——`%Objects.Object{}` 模式匹配需 `alias Maxio.Objects.Object`？不需要：`Objects.Object` 是有效全限定 struct 名。但为稳妥，executor 可在模块头加 `alias Maxio.Objects` 后用 `%Objects.Object{}`（Elixir 允许嵌套别名 struct 写法）。**若编译器抱怨**，改为 `alias Maxio.Objects.Object`（与 `alias Maxio.{Objects, Storage}` 共存：写 `alias Maxio.{Objects, Storage}` + `alias Maxio.Objects.Object`）。

```elixir
  @impl true
  def handle_event("save_upload", _params, socket) do
    bucket = socket.assigns.bucket
    prefix = socket.assigns.prefix
    versioning = socket.assigns.versioning

    consumed =
      consume_uploaded_entries(socket, :object, fn %{path: tmp_path}, entry ->
        key = prefix <> entry.client_name
        version_id = if versioning == "Enabled", do: VersionId.generate(), else: "null"
        chunks = File.stream!(tmp_path, @chunk_bytes)

        case Storage.put(bucket, key, version_id, chunks) do
          {:ok, %{size: size, etag: etag}} ->
            {:ok, obj} =
              Objects.put_version_with_id(bucket, key, version_id, %{
                size: size,
                etag: etag,
                content_type: entry.client_type || "binary/octet-stream",
                storage_class: "STANDARD"
              })

            {:ok, obj}

          {:error, reason} ->
            require Logger
            Logger.error("[maxio][Console] upload failed",
              bucket: bucket,
              key: key,
              reason: inspect(reason)
            )
            {:postpone, {:error, reason}}
        end
      end)

    socket =
      Enum.reduce(consumed, socket, fn
        %Objects.Object{} = obj, acc ->
          # 仅当对象落在当前前缀的直接层级才插 stream（深层归当前文件夹视图外）。
          if direct_child?(obj.key, prefix) do
            acc |> stream_insert(:objects, obj, at: 0) |> update(:object_count, &(&1 + 1))
          else
            acc
          end

        {:error, _reason}, acc ->
          put_flash(acc, :error, "部分文件上传失败")
      end)

    {:noreply, put_flash(socket, :info, "上传完成")}
  end

  @impl true
  def handle_event("create_folder", %{"folder" => %{"folder" => folder}}, socket) do
    bucket = socket.assigns.bucket
    prefix = socket.assigns.prefix
    name = String.trim(folder)

    cond do
      name == "" ->
        {:noreply, put_flash(socket, :error, "文件夹名不能为空")}

      String.contains?(name, "/") ->
        {:noreply, put_flash(socket, :error, "文件夹名不能含 /")}

      true ->
        key = prefix <> name <> "/"

        case Storage.put(bucket, key, "null", []) do
          {:ok, %{size: size, etag: etag}} ->
            {:ok, _obj} =
              Objects.put_version_with_id(bucket, key, "null", %{
                size: size,
                etag: etag,
                content_type: "application/x-directory"
              })

            {:noreply,
             socket
             |> put_flash(:info, "已创建文件夹 #{name}/")
             |> push_patch(to: ~p"/buckets/#{bucket}/browse?prefix=#{key}")}

          {:error, _reason} ->
            {:noreply, put_flash(socket, :error, "创建文件夹失败")}
        end
    end
  end

  @impl true
  def handle_event("delete_object", %{"key" => key}, socket) do
    bucket = socket.assigns.bucket
    versioning = socket.assigns.versioning

    case Objects.get_metadata(bucket, key) do
      {:ok, obj} ->
        if versioning == "Enabled" do
          {:ok, _} = Objects.insert_delete_marker(bucket, key, versioning)
        else
          :ok = Objects.delete_metadata(bucket, key)
          _ = Storage.delete(bucket, key)
        end

        {:noreply,
         socket
         |> stream_delete(:objects, obj)
         |> update(:object_count, &max(&1 - 1, 0))
         |> put_flash(:info, "已删除 #{key}")}

      {:error, :not_found} ->
        {:noreply, put_flash(socket, :error, "对象不存在")}
    end
  end

  # ── 辅助 ──
  # common prefix 是完整 "prefix.../folder/"——展示去掉当前 prefix 后的末段。
  defp folder_label(cp, prefix) do
    cp |> String.replace_prefix(prefix, "") |> String.trim_trailing("/")
  end

  # 对象展示去掉当前 prefix 的末段。
  defp object_label(key, prefix), do: String.replace_prefix(key, prefix, "")

  # 该 key 是否是当前 prefix 的直接子（去 prefix 后不含 "/"，即非深层）。
  defp direct_child?(key, prefix) do
    rest = String.replace_prefix(key, prefix, "")
    rest != "" and not String.contains?(rest, "/")
  end

  defp error_to_string(:too_large), do: "文件超出大小上限（5 GiB）"
  defp error_to_string(:too_many_files), do: "选择的文件过多（最多 5 个）"
  defp error_to_string(:not_accepted), do: "不接受的文件类型"
  defp error_to_string(other), do: "上传错误: #{inspect(other)}"
end
```

> **`alias Maxio.Objects` + `%Objects.Object{}`**：`save_upload` reduce 里 `%Objects.Object{}` 与 delete 里 `Objects.get_metadata` 共存。`Maxio.Objects.Object` 是嵌套 struct——若 `%Objects.Object{}` 编译报错，改 `alias Maxio.Objects.Object`（与 `alias Maxio.{Buckets, Objects, Storage}` 同列），reduce 子句写 `%Object{} = obj`。**executor 落地时二选一并保持一致**。

```elixir
          <.form for={@tag_form} id="tags-form" phx-submit="save_tags" class="space-y-2">

              field={@tag_form[:raw]}
              type="textarea"

          </.form>

      <%!-- 版本列表 --%>
      <div class="mt-6">
        <h2 class="font-semibold text-sm text-base-content/70 mb-2">版本历史</h2>

                    :if={!v.is_delete_marker}

                    <.icon name="hero-arrow-down-tray" class="size-3" />
                  </.link>
                  <.button
                    id={"delete-version-#{dom_id}"}
                    phx-click="delete_version"
                    phx-value-vid={v.version_id}
                    data-confirm="永久删除该版本？"
                  >
                    <.icon name="hero-trash" class="size-3" />
                  </.button>
                </div>
              </td>
            </tr>
          </tbody>
        </table>
      </div>
    </Layouts.app>
    """
  end

  @impl true
  def handle_event("save_tags", %{"tags" => %{"raw" => raw}}, socket) do
    bucket = socket.assigns.bucket
    key = socket.assigns.key
    tag_list = parse_raw_tags(raw)

    case Tags.validate(tag_list, :object) do
      :ok ->
        case Objects.put_tags(bucket, key, tag_list) do
          :ok ->
            {:noreply,
             socket
             |> assign(:tag_form, tags_to_form(tag_list))
             |> put_flash(:info, "标签已保存")}

          {:error, :not_found} ->
            {:noreply, put_flash(socket, :error, "对象不存在")}
        end

      {:error, :invalid_tag} ->
        {:noreply, put_flash(socket, :error, "标签非法（对象 ≤10 个，键 1-128 / 值 0-256，不可 aws: 前缀）")}
    end
  end

  @impl true
  def handle_event("delete_version", %{"vid" => vid}, socket) do
    bucket = socket.assigns.bucket
    key = socket.assigns.key

    case Objects.delete_version(bucket, key, vid) do
      {:ok, _} ->
        # 重取版本列表（promote_latest 可能改变其他行）+ 重取当前对象。
        versions = versions_for(bucket, key)

        socket =
          case Objects.get_metadata(bucket, key) do
            {:ok, obj} -> assign(socket, :object, obj)
            {:error, :not_found} -> socket
          end

        {:noreply,
         socket
         |> stream(:versions, versions, reset: true)
         |> put_flash(:info, "已删除版本 #{vid}")}

      {:error, :not_found} ->
        {:noreply, put_flash(socket, :error, "版本不存在")}
    end
  end

  # ── 辅助 ──
  defp versions_for(bucket, key) do
    %{versions: versions} = Objects.list_object_versions(bucket, %{prefix: key, max_keys: 1000})
    Enum.filter(versions, &(&1.key == key))
  end

  # tag list → 表单（raw 文本：每行 key=value）。
  defp tags_to_form(tag_list) do
    raw = tag_list |> Enum.map(fn {k, v} -> "#{k}=#{v}" end) |> Enum.join("\n")
    to_form(%{"raw" => raw}, as: :tags)
  end

  # raw 文本（每行 key=value）→ [{k,v}]（忽略空行）。
  defp parse_raw_tags(raw) do
    raw
    |> String.split(~r/\r?\n/, trim: true)
    |> Enum.map(&String.trim/1)
    |> Enum.reject(&(&1 == ""))
    |> Enum.map(fn line ->
      case String.split(line, "=", parts: 2) do
        [k, v] -> {String.trim(k), String.trim(v)}
        [k] -> {String.trim(k), ""}
      end
    end)
  end

  defp meta(assigns) do
    ~H"""
    <div class="flex gap-3 text-sm">
      <span class="w-32 shrink-0 text-base-content/60">{@label}</span>
      <span class="font-mono break-all">{@value}</span>
    </div>
    """
  end

  attr :label, :string, required: true
  attr :value, :any, required: true
  defp meta(assigns), do: meta(assigns)
end
```

> **修正**：`meta/1` 的 `attr` 声明必须**在函数定义之前**，且不能有重复定义（上面末尾 `defp meta(assigns), do: meta(assigns)` 是错误的占位——删掉它）。正确写法：把 `attr :label`/`attr :value` 两行放在 `defp meta(assigns) do ~H...` **之前**，删除末行重复定义。executor 落地时把 meta 组件写成：
>
> ```elixir
>   attr :label, :string, required: true
>   attr :value, :any, required: true
>   defp meta(assigns) do
>     ~H"""
>     <div class="flex gap-3 text-sm">
>       <span class="w-32 shrink-0 text-base-content/60">{@label}</span>
>       <span class="font-mono break-all">{@value}</span>
>     </div>
>     """
>   end
> ```

```elixir
      {@label}

  # ── 表单装配 ──
  defp load_forms(socket, b) do
    bucket = b.name

    policy_json =
      case Store.get_bucket_policy(bucket) do
        {:ok, json} -> json
        :none -> ""
      end

    cors_json = config_json(bucket, :cors)
    lifecycle_json = config_json(bucket, :lifecycle)
    encryption_algo = encryption_algo(bucket)
    {:ok, bucket_tags} = Buckets.get_tags(bucket)

    socket
    |> assign(:versioning_form, to_form(%{"status" => b.versioning}, as: :versioning))
    |> assign(:policy_form, to_form(%{"json" => policy_json}, as: :policy))

    |> assign(:tags_form, to_form(%{"raw" => tags_raw(bucket_tags)}, as: :tags))
    |> assign(:cors_form, to_form(%{"json" => cors_json}, as: :cors))
    |> assign(:lifecycle_form, to_form(%{"json" => lifecycle_json}, as: :lifecycle))
    |> assign(:encryption_form, to_form(%{"algorithm" => encryption_algo}, as: :encryption))
  end

  defp config_json(bucket, kind) do
    case BucketConfigs.get(bucket, kind) do
      {:ok, value} -> Jason.encode!(value, pretty: true)
      :none -> ""
    end
  end

  defp encryption_algo(bucket) do
    case BucketConfigs.get(bucket, :encryption) do
      {:ok, %{"algorithm" => algo}} -> algo
      {:ok, _} -> "none"
      :none -> "none"
    end
  end

  defp tags_raw(tag_list), do: tag_list |> Enum.map(fn {k, v} -> "#{k}=#{v}" end) |> Enum.join("\n")

  # ── handle_event ──
  @impl true
  def handle_event("save_versioning", %{"versioning" => %{"status" => status}}, socket) do
    bucket = socket.assigns.bucket
    # "Unversioned" 不是 PutBucketVersioning 合法 status；映射为 Suspended（AWS 无法回退到 never-set）。
    arg = if status == "Unversioned", do: "Suspended", else: status
    :ok = Buckets.put_versioning(bucket, arg, nil)
    {:ok, b} = Buckets.lookup(bucket)
    {:noreply, socket |> assign(:bucket_struct, b) |> load_forms(b) |> put_flash(:info, "版本化已更新")}
  end

  @impl true
  def handle_event("save_policy", %{"policy" => %{"json" => json}}, socket) do
    bucket = socket.assigns.bucket
    trimmed = String.trim(json)

    cond do
      trimmed == "" ->
        :ok = Store.delete_bucket_policy(bucket)
        {:noreply, put_flash(socket, :info, "策略已删除")}

      true ->
        case Statement.parse_policy(trimmed) do
          {:ok, _stmts} ->
            :ok = Store.put_bucket_policy(bucket, trimmed)
            {:noreply, put_flash(socket, :info, "策略已保存")}

          {:error, _} ->
            {:noreply, put_flash(socket, :error, "策略 JSON 非法（MalformedPolicy）")}
        end
    end
  end

  @impl true
  def handle_event("save_acl", %{"acl" => %{"canned" => canned}}, socket) do
    bucket = socket.assigns.bucket

    if canned in @canned do
      :ok = Buckets.put_acl(bucket, canned)
      {:noreply, put_flash(socket, :info, "ACL 已更新为 #{canned}")}
    else
      {:noreply, put_flash(socket, :error, "不支持的 canned ACL")}
    end
  end

  @impl true
  def handle_event("save_bucket_tags", %{"tags" => %{"raw" => raw}}, socket) do
    bucket = socket.assigns.bucket
    tag_list = parse_raw_tags(raw)

    case Tags.validate(tag_list, :bucket) do
      :ok ->
        :ok = Buckets.put_tags(bucket, tag_list)
        {:noreply, put_flash(socket, :info, "桶标签已保存")}

      {:error, :invalid_tag} ->
        {:noreply, put_flash(socket, :error, "标签非法（桶 ≤50 个，不可 aws: 前缀）")}
    end
  end

  @impl true
  def handle_event("save_cors", %{"cors" => %{"json" => json}}, socket) do
    bucket = socket.assigns.bucket
    save_config_json(socket, bucket, :cors, json, "CORS")
  end

  @impl true
  def handle_event("save_lifecycle", %{"lifecycle" => %{"json" => json}}, socket) do
    bucket = socket.assigns.bucket
    save_config_json(socket, bucket, :lifecycle, json, "生命周期")
  end

  @impl true
  def handle_event("save_encryption", %{"encryption" => %{"algorithm" => algo}}, socket) do
    bucket = socket.assigns.bucket

    cond do
      algo == "none" ->
        :ok = BucketConfigs.delete(bucket, :encryption)
        {:noreply, put_flash(socket, :info, "默认加密已关闭")}

      algo == "AES256" ->
        :ok = BucketConfigs.put(bucket, :encryption, %{"algorithm" => "AES256"})
        {:noreply, put_flash(socket, :info, "默认加密已设为 SSE-S3 (AES256)")}

      true ->
        {:noreply, put_flash(socket, :error, "SSE-KMS 尚未实现（绝不静默当 AES256）")}
    end
  end

  # 通用 JSON 配置保存（cors/lifecycle）：空 = 删除；非法 JSON = 错误 flash。
  defp save_config_json(socket, bucket, kind, json, label) do
    trimmed = String.trim(json)

    cond do
      trimmed == "" ->
        :ok = BucketConfigs.delete(bucket, kind)
        {:noreply, put_flash(socket, :info, "#{label} 已删除")}

      true ->
        case Jason.decode(trimmed) do
          {:ok, value} ->
            case BucketConfigs.put(bucket, kind, value) do
              :ok -> {:noreply, put_flash(socket, :info, "#{label} 已保存")}
              {:error, _} -> {:noreply, put_flash(socket, :error, "#{label} 保存失败")}
            end

          {:error, _} ->
            {:noreply, put_flash(socket, :error, "#{label} JSON 非法")}
        end
    end
  end

  defp parse_raw_tags(raw) do
    raw
    |> String.split(~r/\r?\n/, trim: true)
    |> Enum.map(&String.trim/1)
    |> Enum.reject(&(&1 == ""))
    |> Enum.map(fn line ->
      case String.split(line, "=", parts: 2) do
        [k, v] -> {String.trim(k), String.trim(v)}
        [k] -> {String.trim(k), ""}
      end
    end)
  end
end
```

> **注意 `load_forms/2` 返回 socket**——`mount` 里 `|> load_forms(b)` 与 handler 里 `|> load_forms(b)` 都把 socket 串进去（第一个参数）。上面定义是 `load_forms(socket, b)`，与管道一致。
>
> **CORS/lifecycle JSON 形态**：`BucketConfigs.put(bucket, :cors, value)` 期望已解析的 list（S3 端由 saxy parser 产出 string-key map list）。Console 用裸 JSON 编辑（高级用户友好），`Jason.decode` 后直接存（jsonb）。该 JSON 形态对齐 `Maxio.S3.Views.Cors`/`Lifecycle` 的内部 map 结构（`allowed_origins`/`allowed_methods` 等）。**VERIFY-AT-IMPL: Console CORS JSON 形态**——executor 落地时读一份 `Maxio.S3.RequestParsers.Cors.parse/1` 输出样例（或 S3 端 round-trip 的 jsonb），在 CORS tab 的 placeholder/帮助文本给出一个合法范例，避免用户写出 S3 端无法匹配的形态。MVP 接受裸 JSON 存储 + 提示。

```elixir
defmodule MaxioWeb.AccessKeyLive.Index do
  use MaxioWeb, :live_view

  alias Maxio.IAM

  @impl true
  def mount(_params, _session, socket) do
    keys = IAM.list_access_keys()

    {:ok,
     socket
     |> assign(:page_title, "Access Keys")
     |> assign(:key_count, length(keys))
     |> assign(:new_secret, nil)
     |> stream(:keys, keys, dom_id: &"keys-#{&1.access_key_id}")}
  end

  @impl true
  def render(assigns) do
    ~H"""
    <Layouts.app flash={@flash} current_scope={@current_principal}>
      <.header>
        Access Keys
        <:subtitle>{@key_count} 个密钥</:subtitle>
      </.header>

      <div :if={@new_secret} id="new-secret-banner" class="alert alert-success mb-4 text-sm">
        <.icon name="hero-check-circle" class="size-5" />
        <div>
          <p class="font-semibold">新密钥已创建（Secret 仅显示这一次，请妥善保存）：</p>
          <p class="font-mono">Access Key: {@new_secret.access_key_id}</p>
          <p class="font-mono">Secret Key: {@new_secret.secret_key}</p>
        </div>
      </div>

      <.form for={%{}} as={:key} id="create-key-form" phx-submit="create_key" class="mb-6">
        <.button variant="primary" id="create-key-submit" type="submit">
          <.icon name="hero-plus" class="size-4" /> 创建 Access Key
        </.button>
      </.form>

      <table class="table table-zebra">
        <thead>
          <tr><th>Access Key ID</th><th>类型</th><th>状态</th><th>ARN</th><th class="w-0"></th></tr>
        </thead>
        <tbody id="access-keys" phx-update="stream">
          <tr class="hidden only:table-row" id="access-keys-empty">
            <td colspan="5" class="text-center text-base-content/60">暂无 access key</td>
          </tr>
          <tr :for={{dom_id, k} <- @streams.keys} id={dom_id}>
            <td class="font-mono text-sm">{k.access_key_id}</td>
            <td>
              <span class={[
                "badge badge-sm",
                k.type == "root" && "badge-primary",
                k.type != "root" && "badge-ghost"
              ]}>
                {k.type}
              </span>
            </td>
            <td>{k.status}</td>
            <td class="font-mono text-xs text-base-content/60">{k.principal_arn}</td>
            <td>
              <.button
                id={"delete-key-#{k.access_key_id}"}
                phx-click="delete_key"
                phx-value-ak={k.access_key_id}
                data-confirm={"删除 access key #{k.access_key_id}？"}
              >
                <.icon name="hero-trash" class="size-4" />
              </.button>
            </td>
          </tr>
        </tbody>
      </table>
    </Layouts.app>
    """
  end

  @impl true
  def handle_event("create_key", _params, socket) do
    case IAM.create_access_key() do
      {:ok, %{access_key_id: ak, principal_arn: arn, type: type} = created} ->
        row = %{access_key_id: ak, principal_arn: arn, type: type, status: "active"}

        {:noreply,
         socket
         |> stream_insert(:keys, row, at: 0)
         |> update(:key_count, &(&1 + 1))
         |> assign(:new_secret, created)
         |> put_flash(:info, "已创建 access key #{ak}")}

      {:error, _cs} ->
        {:noreply, put_flash(socket, :error, "创建失败")}
    end
  end

  @impl true
  def handle_event("delete_key", %{"ak" => ak}, socket) do
    case IAM.delete_access_key(ak) do
      :ok ->
        {:noreply,
         socket
         |> stream_delete(:keys, %{access_key_id: ak})
         |> update(:key_count, &max(&1 - 1, 0))
         |> assign(:new_secret, nil)
         |> put_flash(:info, "已删除 #{ak}")}

      {:error, :cannot_delete_last_root} ->
        {:noreply, put_flash(socket, :error, "不能删除最后一个 root 密钥")}
    end
  end
end
```

> **`dom_id` 自定义**：access key 行 map 无 `:id` 字段——`stream/3` 默认 `dom_id` 取 `item.id` 会崩。故 `stream(:keys, keys, dom_id: &"keys-#{&1.access_key_id}")`，`stream_delete` 传 `%{access_key_id: ak}`（dom_id 函数仅用 `access_key_id`，匹配成立）。`stream_insert` 同理用 map（dom_id 函数算出 `keys-<ak>`）。

## 附录 A：常见陷阱与对策（executor 必读）

1. **test 凭据 ≠ dev 凭据**：test 用 MemoryStore root `AKIAIOSFODNN7EXAMPLE`/`wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY`（`config/test.exs`）；dev 用 EctoStore root `minioadmin`/`minioadmin`。`log_in_console/2` 默认前者。
2. **`Maxio.Objects.Object` struct 别名**：模式匹配/构造用 `%Objects.Object{}` 需 `alias Maxio.Objects`（嵌套 struct 写法 Elixir 支持）；若编译器抱怨，改 `alias Maxio.Objects.Object` 后用 `%Object{}`。保持单一选择。
3. **stream 计数**：streams 不可计数——所有列表页用单独 `:*_count` assign，增删时 `update`。
4. **stream_delete 需真实 struct/带 id 的 map**：bucket 用 `Buckets.lookup` 拿 `%Bucket{}`；object 用 `get_metadata` 拿 `%Object{}`；access key 用自定义 `dom_id` + `%{access_key_id: ak}` map。
5. **空态 `hidden only:table-row`**：空态 `<tr>` 必须是 stream for-comprehension 的**唯一同级静态块**（同一 `<tbody phx-update="stream">` 内），否则 `only:` 失效。文件夹（common_prefixes）放在**另一个** `<tbody>`（非 stream），不破坏 objects stream 的空态。
6. **prefix 导航重 stream**：`handle_params` 切 prefix 时 `stream(:objects, objects, reset: true)`（不是 insert）。
7. **上传不静默**：`consume_uploaded_entries` 回调失败返回 `{:postpone, {:error, reason}}` + `[maxio][Console]` 标签 `Logger.error` + flash；绝不 `{:ok, nil}` 吞错。
8. **下载 plain controller**：LiveView 不能流 binary；下载走 `get "/buckets/:bucket/download/*key"` + `send_chunked` + `Enum.reduce_while`（`{:error,:closed}` halt）。下载链接用 `<.link href=...>`（全 HTTP GET），**非** `navigate`/`patch`。
9. **`<.flash_group>` 仅 layouts.ex**：LiveView 模板里**绝不**调；flash 经 `<Layouts.app flash={@flash}>` 自动渲染。
10. **登录页 `layout: false`**：SessionController `render(conn, :new, layout: false)`；登录不套 app shell。
11. **CSRF**：`<.form action=... method="post">` 自动注入 `_csrf_token`；登出 `<.link method="delete">` 同理（`Plug.MethodOverride`）。
12. **`versioning` "Unversioned" 非合法 PutBucketVersioning status**：Settings 的 versioning select 给 Unversioned 选项时，handler 把它映射为 `"Suspended"`（AWS 无法回 never-set），文档化。
